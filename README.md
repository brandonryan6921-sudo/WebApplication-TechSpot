####################### Setup Instructions #############################

Below are the setup instructions to run the web application source 
					          code locally on your device.

1. Extract the project folder
2. In the backend folder rename .env.example to .env

Backend:
3. cd backend
4. npm install
5. npm run start

Frontend:
6. cd frontend
7. npm install
8. npm run dev
9. Open http://localhost:3000

Note: All dependencies are pre-configured in package.json. 
Simply run npm install in both folders to get started.
